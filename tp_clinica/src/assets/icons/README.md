# Iconos para Selección de Tipo de Usuario

Este directorio debe contener los iconos para la selección de tipo de usuario en el registro.

## Archivos necesarios:

- `paciente-icon.png` - Icono representativo para pacientes
- `especialista-icon.png` - Icono representativo para especialistas

## Especificaciones:
- Formato: PNG (preferible por transparencia)
- Tamaño recomendado: 128x128px o 256x256px
- Fondo transparente
- Diseño simple y claro

## Nota:
Actualmente el sistema usa iconos de FontAwesome como fallback. Estos archivos de imagen son opcionales pero pueden mejorar la apariencia visual.
